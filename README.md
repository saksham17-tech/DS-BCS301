## 📌 Overview

This repository contains well-structured, readable, and efficient implementations of fundamental **Data Structures** as per the **BCS301** curriculum (AKTU / similar B.Tech programs).

Every program is written with:
- Clarity and simplicity
- Proper memory management
- Focus on understanding core concepts
- Practical problem-solving approach

Perfect for **students**, **lab work**, **exam preparation**, and **interview practice**.

## 🗂️ Repository Structure

| Folder | Contents | Key Topics |
|:------:|----------|------------|
| **`arrLL`** | Arrays & Linked Lists | Dynamic arrays, Singly/Doubly/Circular Linked Lists |
| **`SQR`** | Stacks, Queues & Related | Stack, Queue, Circular Queue, Deque, Tower of Hanoi, Polynomial Addition, Valid Parentheses |
| **`trees`** | Trees | Binary Trees, BST, Traversals, Heaps |
| **`sorting`** | Sorting Algorithms | Bubble, Selection, Insertion, Merge, Quick, Heap, Radix |
| **`graphs`** | Graphs & Algorithms | Graph representation, BFS/DFS, Dijkstra, Prim, Floyd-Warshall, Warshall |
